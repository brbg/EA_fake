## 一、PPT 大纲（11 页）

### P1 封面
- 标题：AI 原生企业架构建模平台
- 副标题：一句话出图 · 智能协作 · 设计直接落地代码
- 首页截图

### P2 行业痛点
- 建模门槛高：只有资深架构师会画 UML / ArchiMate
- 画图费时：一张复杂类图手工画一两天
- 设计与开发脱节：架构图画完就束之高阁
- 团队协作混乱：多人改同一份图互相覆盖

### P3 方案总览
- AI 原生全流程平台：描述 → 建模 → 校验/评审 → 生成代码/数据库 → 团队协作
- 三大支柱：智能建模 / 内核级 AI / 落地与协作

### P4 支柱一：智能建模（3 亮点）
1. 自由智能画布：UML / ArchiMate / ER 三套画布，自由拖拽、元素自适应、自动防重叠布局
2. 一键自然语言生成类图：一句话 / 一段需求，AI 秒级生成对应模型（含需求文档直接建模）
3. 23 种设计模式智能库：一键插入模式模板；AI 分析当前架构推荐最合适模式并可覆盖重写

### P5 支柱二：内核级 AI（4 亮点）
1. 内核级 AI 嵌入：贯穿建模、校验、评审、生成、协作全流程
2. 智能 AI 协助：校验语义、架构评审、元素分析、对话式编辑、深度思考
3. AI 项目知识库（个性化）：自动记录每次结论，后续生成参考项目全貌
4. 健康度分析：一键架构体检，AI 深度分析给评分 + 问题 + 建议

### P6 支柱三：落地与协作（3 亮点）
1. 双流程落地：模型 → Java 代码；ER → MySQL 建表语句（含外键）
2. 多人 GitHub 式协作：实时同步 + 变更审批（提交申请 → 拥有者批准）
3. 模型版本管理：历史可查、一键回滚，企业级数据安全

### P7 技术架构
- 前端：Vue3 + TypeScript + Vite
- 后端：Flask + Flask-SocketIO（WebSocket 实时）
- 存储：SQLite；AI：DeepSeek（深度思考推理模型）
- 部署：2核2G 云服务器 + systemd 常驻，公网可访问

### P8 企业应用价值
- 降门槛：业务人员用自然语言参与建模
- 提效率：架构设计从天级到分钟级
- 保质量：AI 校验/评审/健康度，写代码前发现问题
- 强协作：多人实时 + 变更审批，有管控有留痕

### P9 演示截图（3 张）
- AI 生成类图 / 设计模式推荐 / 健康度看板

### P10 总结
- 一句话：从"业务的一句话"到"可运行的代码和数据库"，AI 原生平台全流程承接
- 谢谢 / Q&A

## 三、演示视频分镜（4 分钟）

| 段 | 时间 | 画面 | 讲解 |
|---|---|---|---|
| 开场 | 10s | 网站首页 | 已部署公网的 AI 原生建模平台 |
| 账号系统 | 20s | 注册→右上角 6 位 UID | 每账户独立 UID，用于协作互认 |
| AI 生成 | 60s | 需求→模型→AI 出图→设计模式推荐→覆盖 | 一句话出图；AI 推荐最合适模式 |
| 双流程落地 | 30s | 生成 Java 代码 + MySQL | 图直接变代码和数据库 |
| 协作 | 50s | 双浏览器：输 UID 加入→实时→提交申请→批准 | 多人实时 + 变更审批 |
| 知识库+健康度 | 40s | 健康度评分→知识库自动记录 | AI 记住项目、体检架构 |
| 收尾 | 10s | 手机外网打开 | 任何地方可访问 |

录制要点：
- 双浏览器并排（普通 + 无痕）
- 每段先讲目的再操作
- AI 调用前说"稍等一下"
- 结尾手机流量开一次证明公网可访问
