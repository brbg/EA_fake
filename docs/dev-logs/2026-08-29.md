## 触屏/交互 bug 修复（第二轮）

### 6. 无限画布触屏/交互四大 bug（线上实测发现，根因同类：逻辑坐标 vs 屏幕坐标）
- **pinch 双指缩放乱跳**：原用逻辑坐标（`toLogical`）跟踪触点，视图缩放后触点坐标随之变化 → 两指距离失真、scale 反复横跳。改：触点用**屏幕坐标**（clientX/Y，不受视图影响）算距离，焦点用 `zoomAtPoint` 每次基于当前视图精确换算 → 无反馈循环。
- **画布无法拖动（触屏 + 电脑）**：原平移用逻辑坐标差值（`x - panStartX`），而 `toLogical` 返回值含视图偏移，视图每帧更新后差值混入上一帧位移 → **累积漂移**（越拖越飞）。改：平移用**屏幕位移 / scale**，每帧精确跟随，无累积。
- **三击删除会生成新类且删不掉**：原方案依赖浏览器 `dblclick` 设置待编辑，但触屏上 dblclick 常常不触发 → 三击检测失效，每次点击都走创建逻辑。改：**纯 click 计数**判定三击（350ms 窗口 + 12 逻辑像素容差 + 第一击锚定元素防抖动），快速连点的中间击不创建元素。
- **缩放后放置元素不可见**：① 平移漂移修复后视图不再乱跑；② 拖动阈值改**逻辑像素**（放大时折算更大屏幕位移），点击微动不易被误判为拖动而吞掉点击。

### 7. 关系基数选择无反应 / 卡「一对多」/ 不自动关闭
- 根因：`connections` 是普通数组（非响应式），`selConnCardinality` computed 在 `setConnCardinality` 修改 `cardinality` 后不重算 → 按钮高亮一直停在默认「一对多」（画布标签因 `redraw()` 正常）。
- 修复：加 `connCardTick` 计数器建立 computed 依赖强制重算；选完基数后清空 `selectedConnectionId` 自动收起工具栏。

### 8. 「画布拖不动」真正根因：平移只改 view 没重新应用 canvas 变换
- 前一轮只改了 view 数值（数学验证通过），但 **`viewPanning` 分支漏了 `setupCanvasTransform`** → ctx 的 transform 仍是旧视图，画面不跟随 → 看起来「拖不动」（电脑/触屏都一样）。
- 修复：三套画布的 viewPanning 分支更新 view 后补 `setupCanvasTransform(canvas)` 再 redraw。

### 9. 触屏双击/三击在缩放后失效
- 根因一：连击判定（rapid）用**逻辑坐标**容差，缩放改变逻辑位移 → 缩小后 tap 抖动易超容差、判定失效。修复：rapid 改用**屏幕坐标**（固定 16 物理像素），与缩放完全解耦。
- 根因二：双击编辑依赖浏览器 `dblclick`（触屏合成不稳定）；且连击计数会被「创建元素的 click」污染（创建后 350ms 内双击 → 计数错乱变三击误删）。修复：双击编辑改为 **click 计数延迟**（tapCount==2 定时打开编辑框，不依赖 dblclick）；连击必须「时间窗口 + 屏幕位置 + **命中同一元素**」才累加，避免创建/点空白污染。
- 实测（Edge headless + 真实 touch 事件）：缩小 0.8 / 放大 1.95 三击删除 ✓；scale 1 / 1.95 双击编辑 ✓。

### 10. 页面（tab 内容）切换过渡动画
- 用户要求：切换页面时加过渡、变慢变丝滑（画布交互保持现状）。
- 实现：所有 tab 内容包进 `<Transition name="page-fade" mode="out-in">` + `<div :key="activeTab">`（切换时先淡出再淡入）。
- 过渡 CSS：opacity + 轻微位移（translateY 18px→0），0.45s `cubic-bezier(0.22,1,0.36,1)`（丝滑收尾）。
- 实测（Edge headless）：切换时 `.page-fade-leave-active` 生效（out-in 正常），过渡完成后 canvas/dashboard 内容渲染正常。
