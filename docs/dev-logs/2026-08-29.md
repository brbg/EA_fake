# 开发日志 · 2026-08-29

## 今日主题

**画布交互全面升级：无限画布 + 触屏适配（pinch 双指缩放 / 拖动平移 / 悬浮缩放按钮 / 平滑过渡动画）+ 三击删除 + toast 自动关闭 + 公开演示版定位。**

## 完成事项

### 1. 无限画布完整化（三套画布：UML / ArchiMate / ER）
- 逻辑坐标 1150×600 + `canvasUtils.ts` 的 `CanvasView`（x/y/scale，WeakMap 关联各画布）统一 transform；元素/连线全部画在逻辑坐标下，随画布平移缩放。
- **触屏双指捏合缩放（pinch）**：新增多指触点跟踪 `activePointers`，第二指按下进入 pinch，以两指中心为焦点缩放 + 中心跟随（[App.vue](../../EA_fake/ea-webapp/src/App.vue)）。
- **拖动阈值平移**：空白处按下先记为「候选平移」，拖动超过 6 逻辑像素才真正平移 → 区分「点击」与「拖动」；**除连线/关系工具外，任意工具拖动空白都平移**（轻点仍创建/选中），触屏与鼠标统一。
- **悬浮缩放按钮组**：三套画布右上角「− 放大 + 百分比 复位」，以画布可见中心为焦点（`.canvas-zoom-controls`）。
- **平滑过渡动画**：滚轮/按钮缩放走 `requestAnimationFrame` + easeOutCubic 插值（焦点保持不动，视觉围绕焦点缩放）；pinch/拖动手势期间自动打断动画（实时跟手）。

### 2. 事件体系理顺
- 三套画布的 pointermove/pointerup 改为只挂 document（模板不再重复绑定 canvas 级），init 时先移除所有画布监听再注册当前画布 → 切 tab 不再累积多个 handler、事件只处理一次（此前同一事件会被 canvas+document 处理两次，pinch 会出问题）。
- 补 `pointercancel` 监听（触屏手势中断时清理触点）。
- 切 tab 时清理未完成的缩放动画/触点/三击等待状态，避免跨画布串台。

### 3. 三击删除元素（与右键删除并行）
- 三套画布均支持**双击编辑、三击删除**：双击打开编辑框改为延迟 350ms，若期间第三次点击同一元素则取消编辑并删除（复用右键删除逻辑：入撤销历史 + 清理关联连线/关系）。

### 4. toast 提示：纯提示 3 秒自动关闭
- [App.vue](../../EA_fake/ea-webapp/src/App.vue) `showToast`：info/success（无需确认的纯提示）3 秒自动关闭；warning/error（需要用户注意的失败/操作提示）保持显示，点 × 关闭；新提示替换时清掉旧定时器。

### 5. 登录页定位：本地演示版 → 公开演示版
- [LoginView.vue](../../EA_fake/ea-webapp/src/LoginView.vue) 页脚文案由「本地演示版 · 数据存储于本机 SQLite」改为「公开演示版 · 数据存储于云服务器」（后端 SQLite 部署于云服务器，数据本就在云端，文案对齐现状）。
