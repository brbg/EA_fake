### 4. Bug 修复
- **flask_socketio 路由上下文广播失败**：`kick_user` 从 HTTP 路由调模块级 `emit`/`leave_room` 会读 `flask.request.namespace`（socket 上下文才有）导致 500。改为 `socketio.emit(..., namespace='/')` + `leave_room(..., namespace='/')`，路由上下文可正常广播 `collab_revoked`/`user_left`/`collab_users`。
