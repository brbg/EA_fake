## 完成事项

### 1. 服务器环境适配
- 目标机是「阿里云 Linux 3 (OpenAnolis)」，**非 Ubuntu**、自带 Python 3.6 太旧 → 用 `dnf install python3.11` 装好 Python 3.11.13 + venv。

### 2. 部署到 /opt/ea-webapp + systemd 常驻
- 本地 `tar`（backend + dist + run.sh + deploy）→ SFTP 上传 → 解压到 `/opt/ea-webapp`。
- 写 `.env`（DeepSeek key：网站专用 `sk-411cd6...`，SECRET_KEY 随机）。
- **systemd 服务** `ea-webapp.service`：开机自启 + 崩溃自动重启 + `MemoryMax=1536M`（nohup 方式会被 SSH 断开杀掉，systemd 才可靠）。
- 阿里云控制台安全组/防火墙放行 8080。

### 3. 部署中发现并修复的三个问题（代码改进）
- [app.py](../../EA_fake/ea-webapp/backend/app.py)：flask_socketio 5.6 在**无交互终端**（生产特征）下拒绝 Werkzeug，加 `allow_unsafe_werkzeug=True`（演示场景官方逃生口）。
- [requirements.txt](../../EA_fake/ea-webapp/backend/requirements.txt)：加 `simple-websocket`，threading 模式下启用真正的 WebSocket 传输（否则实时协作退化为轮询）。
- [run.sh](../../EA_fake/ea-webapp/run.sh)：`PY` 优先 `python3.11`（阿里云 Linux 的 python3 是 3.6），Ubuntu 下回退 `python3`。
