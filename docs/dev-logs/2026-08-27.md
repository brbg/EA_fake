### 4. Bug 修复：撤销/重做/清空后状态栏元素计数不同步
- 根因：`elements`/`archimateElements`/`erEntities` 是**普通数组**（非 ref），状态栏 `{{ elements.length }}` 靠"其它 ref 变化触发重渲染"才顺带刷新；新建/删除调了 `updateStats()` 所以正常，**撤销/重做/清空没调** → 计数不更新。
- 修复：三套画布的 undo/redo/clear 共 9 个函数统一补 `updateStats()`（与删除逻辑一致）。`loadModelFromServer` 已正确调用，无同类漏网。

### 5. Bug 修复：引导首屏定位闪跳二次定位

### 7. 生成代码：新增「MySQL 语句」
- 代码生成页源选 **UML 或 ER** 时，输出类型新增 **MySQL语句**。
- **UML 类图 → 表**：每个类生成 CREATE TABLE（id 主键 AUTO_INCREMENT、属性转列、类型映射到 MySQL 类型）。
- **UML 连线基数标注**：画连线后可点选连线，顶部浮出「一对一 1:1 / 一对多 1:N / 多对多 M:N」工具栏；连线上显示基数标签；MySQL 按基数生成外键（1:1 UNIQUE、1:N FK、M:N 中间表）。
- **ER 模型 → 表 + 外键**：实体转表、关系按基数转 ALTER TABLE 外键 / 中间表。
- 全部 `ENGINE=InnoDB DEFAULT CHARSET=utf8mb4`，本地生成器直接出（不走 AI）。
